Rules:

1. No dataset media in git. Reference by identifier (`asllvd_ref`)
   only; large authored assets (`*.glb`, renders, pose stills) go
   through the existing CloudFront asset pipeline, not this repo
   (see .gitignore). Each shipped sign is a versioned `GLOSS@n`
   animation group with its face pairing in the lexicon entry.
2. Attribution file ships with any public demo: hosts, dataset
   citation, model providers, reviewer credit.
3. If a term is ambiguous, the asset stays out of the public build
   until it is clear. The signing-inset fallback must use licensed
   signer video only.
